# Watch Party（iPhone 用スクリプト）

友達同士で動画を一緒に見るための、iPhone の Safari 拡張「Userscripts」用スクリプトです。

- 招待文に入っている **コミット番号付きのリンク** から入れてください（中身が差し替えられないリンクです）
- このスクリプトは自動で更新されません。新しい版は、新しい招待文のリンクから入れ直します
- `host/` にあるのは、ホスト（作品を選ぶ人）の PC に入れる拡張機能の zip です。これも配られたコミット番号付きのリンクから取ってください
- 同期サーバーとはデータ（再生位置・チャット）をやりとりするだけです。パスワードやカード番号を聞くことはありません

バージョン 0.24.11
